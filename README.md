# Plan-Frame
Analiz edilecek filmlerden plan bazlı görsel örneklerin çıkarılması amacıyla, açık kaynaklı ve  tarayıcı tabanlı bir yazılım olan PlanEkran;, yalnızca yerel ortamda  bulunan MP4 formatındaki video dosyalarıyla çalışacak biçimde tasarlanmıştır, doğrudan web tarayıcısı üzerinden  çalıştırılmaktadır.
